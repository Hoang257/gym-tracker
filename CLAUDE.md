# Дневник зала — трекер тренировок

Личное PWA-приложение для ведения тренировок: чеклист упражнений, ввод весов и
повторов, история прогресса с графиками. Работает офлайн, ставится на телефон как
иконка. Данные хранятся локально в браузере (localStorage), без бэкенда.

## Контекст

Приложение сделано под конкретную программу владельца (набор массы 66,4 → 70 кг,
3 тренировки в неделю: Вт «Верх·Ширина», Чт «Ноги», Сб «Верх·Толщина»; грудь и
спина тренируются дважды в неделю). Цель — убрать ежедневное решение «что тренить»
и встроить правило двойной прогрессии прямо в интерфейс.

## Стек

- React 19 + TypeScript + Vite
- vite-plugin-pwa (service worker, манифест, установка на телефон)
- Хранение: localStorage (ключи `gt_history_v1`, `gt_drafts_v1`, `gt_theme`)
- Без внешних UI-библиотек, стили в `src/index.css` (токены + светлая/темная тема)

## Команды

```bash
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # прод-сборка (tsc + vite build) в dist/
npm run preview  # предпросмотр прод-сборки
```

## Карта файлов

- `src/data/program.ts` — программа тренировок (3 дня, упражнения, диапазоны, шаг прибавки). Правится здесь.
- `src/lib/types.ts` — типы: Exercise, Workout, Session, Draft и т.д.
- `src/lib/storage.ts` — чтение/запись localStorage, экспорт/импорт JSON.
- `src/lib/useStore.ts` — хук состояния: история + черновики, все действия (ввод, отметка, завершение).
- `src/lib/progress.ts` — логика прогресса: прошлый раз, подсказка «+вес», метрика для графика.
- `src/lib/date.ts` — даты, определение сегодняшней тренировки по дню недели.
- `src/components/WorkoutView.tsx` — экран «Тренировка»: выбор дня, карточки, кнопка «Завершить».
- `src/components/ExerciseCard.tsx` — карточка упражнения с чеклистом и полями подходов.
- `src/components/HistoryView.tsx` — экран «История»: статистика, прогресс, журнал.
- `src/components/Sparkline.tsx` — мини-график (inline SVG).
- `src/App.tsx` — оболочка: вкладки, тема, экспорт/импорт.

## Модель данных

- **Session** — завершенная тренировка: `{ id, date, ts, dayKey, logs: [{ id, sets:[{w,r}], done }] }`.
- **Draft** — незавершенная тренировка (автосохранение по ходу), ключ `${date}_${dayKey}`.
- При открытии дня черновик прегенерируется: вес подставляется из прошлой такой же
  тренировки, повторы пустые.

## Что дальше (роадмап)

1. **Деплой на Vercel** — цель владельца. Нужен аккаунт Vercel (через GitHub).
   Затем `npm i -g vercel && vercel` из папки проекта, либо импорт репозитория в веб-интерфейсе.
   После деплоя открыть ссылку на телефоне → «Добавить на главный экран».
2. **PNG-иконки** для установки (сейчас только `public/icon.svg`). Для iOS желательны
   apple-touch-icon 180×180 и иконки 192/512 PNG в манифесте.
3. **Реальные стартовые веса** владельца — можно зашить как дефолтные плейсхолдеры
   в `program.ts` или просто ввести в первую тренировку (дальше подставляются сами).
4. Идеи на будущее: таймер отдыха между подходами, заметки к тренировке,
   недельный обзор объема по группам мышц, напоминания.

## Заметки по поведению

- После «Завершить» черновик пересоздается пустым (готов к следующему разу) —
  это ожидаемо. Возможное улучшение: авто-переход на вкладку «История».
- Прогресс по упражнению показывается, только когда есть числовые данные
  (отмеченное упражнение без введенного веса/повторов в график не попадает).
